# Ansible

Ansible działa na osobnej maszynie ANSIBLE01 z Rocky Linux. Repozytorium i playbooki znajdują się na tej maszynie. Pliki są edytowane z Windows przez VS Code.

Ansible zarządza sześcioma hostami Rocky Linux: CP01, CP02, CP03, WK01, WK02 i WK03.

Playbooki znajdują się w `ansible/playbooks/`
